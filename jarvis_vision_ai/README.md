# JARVIS-AETHER: Sci-Fi Multimodal AI Desktop Automation System
> **100% Free & Open-Source | Zero Paid APIs | No Subscription Needed**

---

## 🌟 ওভারভিউ (Overview)

**JARVIS-AETHER** হলো একটি নেক্সট-লেভেল মাল্টিমডাল ডেস্কটপ অটোমেশন সিস্টেম, যা সায়েন্স-ফিকশন মুভির টনি স্টার্কের ল্যাবের মতো অভিজ্ঞতা দেয়। এটি দিয়ে কম্পিউটার স্পর্শ না করেই শুধুমাত্র **হাতের ইশারা (Hand Gestures)**, **চোখের পলক ও মুখের উপস্থিতি (Face & Eye Tracking)** এবং **কণ্ঠস্বর (Multilingual Voice: বাংলা, English, اردو, العربية)** দিয়ে উইন্ডোজ কম্পিউটার সম্পূর্ণ নিয়ন্ত্রণ করা যায়।

## 🚀 ক্লাসের সামনে সেরা হওয়ার জন্য লাইভ ডেমো স্ক্রিপ্ট (Step-by-Step Presentation Script)

ক্লাসের সামনে প্রেজেন্টেশন দেওয়ার সময় এই ৫টি ধাপ অনুসরণ করলে শিক্ষক ও সহপাঠীরা সত্যি অবাক হবেন:

### ধাপ ১: সিস্টেমে প্রবেশ ও স্বাগত সম্ভাষণ (Face Detection)
- ল্যাপটপ অন করে `run.bat`-এ ডাবল ক্লিক করুন।
- ক্যামেরার সামনে বসুন।
- **ম্যাজিক:** আপনার মুখ ক্যামেরায় শনাক্ত হতেই সিস্টেম নিজে থেকে রোবোটিক ভয়েসে বলবে:
  > *"Welcome back, Boss. All automation protocols armed, sir."*
- স্ক্রিনে সাইবারপাঙ্ক HUD-তে আপনার মুখের চারপাশে সাই-ফাই গ্রিড ও চোখের ব্লিংক কাউন্টার ভেসে উঠবে।

### ধাপ ২: এয়ার মাউস ও কার্সর চালনা (Air Mouse Mode)
- হাত তুলে তর্জনী (Index Finger) নাড়ান। মাউস না ছুঁয়েই স্ক্রিনের কার্সর আপনার আঙুলের সাথে মাখনের মতো মসৃণভাবে নড়বে।
- বৃদ্ধাঙ্গুল ও তর্জনী দিয়ে চিমটি (Pinch) কাটুন -> সাথে সাথে **লেফট ক্লিক** হবে!
- চিমটি ধরে রেখে ড্র্যাগ করুন বা দুই আঙুল দিয়ে পেজ স্ক্রল করুন।

### ধাপ ৩: বাতাসে দাগ কেটে আঁকাআঁকি (Air Canvas / Draw Mode)
- মুখে বলুন: **"জার্ভিস ড্রয়িং মোড"** বা কিবোর্ডে **M** চাপুন।
- বাতাসে তর্জনী দিয়ে লিখুন বা বৃত্ত/তীরচিহ্ন আঁকুন। স্ক্রিনে নিয়ন রঙে আঁকা ফুটে উঠবে!
- তর্জনী ও মধ্যমা তুলে বাতাসে লেজার পয়েন্টার দিয়ে স্লাইডের গুরুত্বপূর্ণ অংশ দেখান।
- হাতের মুঠো বন্ধ করলেই (Fist) বা মুখে **"মুছে ফেলো"** বললেই পুরো ক্যানভাস ক্লিন হয়ে যাবে!

### ধাপ ৪: স্লাইড সোয়াইপ ও প্রেজেন্টেশন কন্ট্রোল (Presentation Copilot)
- মুখে বলুন: **"স্লাইড মোড"** বা কিবোর্ডে **M** চাপুন।
- হাত বামে থেকে ডানে দ্রুত সোয়াইপ করুন -> **পরের স্লাইড** ওপেন হবে!
- ডানে থেকে বামে সোয়াইপ করুন -> **আগের স্লাইড** ওপেন হবে!
- কোনো স্লাইড ক্লিকার ছাড়াই শুধু বাতাসের ইশারায় প্রেজেন্টেশন চালান।

### ধাপ ৫: বহুভাষিক ভয়েস অটোমেশন জাদু (Multilingual Voice Commands)
- এবার সবাইকে তাক লাগাতে একে একে কমান্ড দিন:
  - **বাংলা:** *"জার্ভিস ব্রাউজার খোলো"* -> গুগল ক্রোম ওপেন হবে!
  - **বাংলা:** *"স্ক্রিনশট নাও"* -> স্বয়ংক্রিয়ভাবে স্ক্রিনশট নিয়ে সেভ করবে এবং জার্ভিস জানাবে: *"Screenshot captured and saved to your pictures folder, sir."*
  - **ইংরেজি:** *"Jarvis, open YouTube"* -> সাথে সাথে ইউটিউব চালু হবে!
  - **উর্দু / আরবি:** *"اسکرین شاٹ لو"* বা *"افتح المتصفح"* বললেও এটি কাজ করবে!
  - জেসচার দিয়ে বুড়ো আঙুল ও তর্জনীর ফাঁক বাড়িয়ে-কমিয়ে ভলিউম কন্ট্রোল দেখান।

## 🎮 কন্ট্রোল এবং কমান্ড তালিকা (Cheat Sheet)

### ১. হাতের ইশারা (Hand Gestures)
| অঙ্গভঙ্গি (Gesture) | ফলাফল (Action) |
|---|---|
| **১ আঙুল (Index)** | মাউস কার্সর মুভ / ক্যানভাসে ড্রয়িং / লেজার পয়েন্টার |
| **Pinch (বুড়ো + তর্জনী)** | লেফট ক্লিক (Left Click) / ড্র্যাগ (Drag) |
| **Pinch (বুড়ো + মধ্যমা)** | রাইট ক্লিক (Right Click) |
| **২ আঙুল উপরে/নিচে** | স্মুথ পেজ স্ক্রল (Scroll Up / Down) |
| **হাত সোয়াইপ (Swipe)** | প্রেজেন্টেশন স্লাইড নেক্সট / প্রিভিয়াস |
| **Pinch দূরত্ব কমানো/বাড়ানো** | ভলিউম কমানো ও বাড়ানো (Volume Slider) |
| **মুঠো বন্ধ (Fist)** | ক্যানভাস পরিষ্কার করা (Clear Screen) |
| **খোলা তালু (Open Palm)** | মিডিয়া প্লে/পজ (Play / Pause) |
| **৩ আঙুল উপরে** | মোড পরিবর্তন (Cycle Mode) |

### ২. ভয়েস কমান্ড (Voice Commands - Multilingual)
| কাজ | কমান্ড (যেকোনো একটি বললেই হবে) |
|---|---|
| **ব্রাউজার খোলা** | *"ক্রোম খোলো"* / *"Open Chrome"* / *"افتح كروم"* / *"کروم کھولو"* |
| **ইউটিউব চালানো** | *"ইউটিউব চালাও"* / *"Open YouTube"* / *"یوٹیوب کھولو"* |
| **স্ক্রিনশট নেওয়া** | *"স্ক্রিনশট নাও"* / *"Take screenshot"* / *"اسکرین شاٹ لو"* |
| **ক্যানভাস মোড** | *"ক্যানভাস মোড"* / *"Draw mode"* / *"کینوس موڈ"* |
| **মাউস মোড** | *"মাউস মোড"* / *"Mouse mode"* / *"ماؤس موڈ"* |
| **ক্যানভাস মোছা** | *"মুছে ফেলো"* / *"Clear canvas"* / *"مٹا دو"* / *"امسح الشاشة"* |
| **স্লাইড বদল** | *"পরের স্লাইড"* / *"Next slide"* / *"الشريحة التالية"* |
| **ডেস্কটপ দেখানো** | *"ডেস্কটপ দেখাও"* / *"Show desktop"* / *"تصغير الكل"* |
| **পিসি লক করা** | *"পিসি লক করো"* / *"Lock system"* / *"قفل الجهاز"* |

### ৩. কিবোর্ড শর্টকাট (Backup Hotkeys)
- **M**: মোড বদল (Mouse -> Canvas -> Slides -> Media)
- **C**: ক্যানভাসে রঙের পরিবর্তন (Cyan -> Green -> Red -> Purple -> Yellow)
- **E**: ক্যানভাস ক্লিন করা
- **L**: ভয়েস ভাষা পরিবর্তন (English -> বাংলা -> اردو -> العربية)
- **S**: স্ক্রিনশট নেওয়া
- **Esc / Q**: সফটওয়্যার বন্ধ করা

## 📁 প্রজেক্ট ফাইল স্ট্রাকচার

```
jarvis_vision_ai/
├── run.bat                   # ১-ক্লিকে প্রজেক্ট চালু করার ব্যাচ ফাইল
├── main.py                   # মূল রানটাইম ও ক্যামেরা অর্কেস্ট্রেটর
├── config.py                 # সংবেদনশীলতা, রঙ ও কমান্ড কনফিগারেশন
├── requirements.txt          # সম্পূর্ণ ফ্রি লাইব্রেরি তালিকা
│
├── core/
│   ├── gesture_engine.py    # হাতের ইশারা ও কার্সর ফিল্টারিং ইঞ্জিন
│   ├── face_eye_engine.py   # মুখ ও চোখের পলক ট্র্যাকিং ইঞ্জিন
│   ├── voice_engine.py      # বাংলা, ইংলিশ, উর্দু, আরবি ভয়েস ও রোবট অডিও
│   └── action_controller.py # উইন্ডোজ ওএস কন্ট্রোল ও স্ক্রিনশট ম্যানেজার
│
├── ui/
│   ├── hud_overlay.py       # সাই-ফাই টনি স্টার্ক HUD ও অডিও ওয়েভফর্ম
│   └── air_canvas.py        # বাতাসে ড্রয়িং ও লেজার পয়েন্টার ইঞ্জিন
│
├── models/                  # অফলাইন গুগল মিডিয়াপাইপ এআই মডেল
└── tests/
    └── test_hardware.py     # হার্ডওয়্যার ও এআই ডায়াগনস্টিক টেস্ট
```
