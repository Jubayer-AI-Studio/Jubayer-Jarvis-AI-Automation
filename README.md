# 🤖 JUBAYER AI // সম্পূর্ণ স্বয়ংক্রিয় হ্যান্ডস-ফ্রি পার্সোনাল সহকারী
> **১০০% ফ্রি এবং ওপেন সোর্স | ক্যামেরা ছাড়া সম্পূর্ণ হাত না দিয়ে পিসি কন্ট্রোল | 100% Hands-Free Voice & Gesture OS Automation**

এই সফটওয়্যারটি তৈরি করা হয়েছে যাতে আপনাকে কীবোর্ড বা মাউসে হাত দিতে না হয়। আপনি বিছানায় শুয়ে বা চেয়ারে বসে শুধুমাত্র **মুখে কথা বলে**, **কন্ঠের বায়োমেট্রিক ভয়েস লক** দিয়ে এবং **মোবাইল ওয়াইফাই রিমোট** ব্যবহার করে আপনার উইন্ডোজ কম্পিউটার সম্পূর্ণভাবে চালাতে পারবেন।

---

## 🚀 এক ক্লিকে চালু করার নিয়ম (Quick Start)

আপনার ডেস্কটপ স্ক্রিনে থাকা **`START_JUBAYER.bat`** ফাইলে ডাবল-ক্লিক করলেই সিস্টেম অন হয়ে যাবে।
অন হওয়ার সাথে সাথে স্ক্রিনের এক কোণে টনি স্টার্কের মতো একটি ভাসমান স্বচ্ছ **'আর্ক রিঅ্যাক্টর' (Arc Reactor Orb)** ফুটে উঠবে।

```bash
# Clone the repository
git clone https://github.com/monisharani333022-eng/Jubayer-Jarvis-AI-Automation.git
cd Jubayer-Jarvis-AI-Automation

# Run setup
INSTALL.bat

# Start the assistant
START_JUBAYER.bat
```

## 🖐️ মূল ফিচারসমূহ (Core Capabilities)

### ১. ⚡ কম্পিউটার পাওয়ার ও উইন্ডোজ কন্ট্রোল (OS Automation)
* **পিসি শাটডাউন:** *"জুবায়ের, পিসি বন্ধ করো"* অথবা *"শাটডাউন করো"*
* **পিসি রিস্টার্ট:** *"জুবায়ের, পিসি রিস্টার্ট করো"*
* **কম্পিউটার লক:** *"জুবায়ের, পিসি লক করো"*
* **উইন্ডো বন্ধ করা:** *"জুবায়ের, উইন্ডো কাটো"* অথবা *"ক্লোজ করো"*
* **ডেস্কটপ দেখা:** *"জুবায়ের, ডেস্কটপ দেখাও"* (সব মিনিমাইজ হবে)
* **উইন্ডো পরিবর্তন (Alt+Tab):** *"জুবায়ের, পরের উইন্ডোতে যাও"*
* **স্ক্রিনশট নেওয়া:** *"জুবায়ের, স্ক্রিনশট নাও"* (ছবি সেভ হবে Pictures ফোল্ডারে)

### ২. 🌐 ইন্টারনেট, গান ও ভিডিও কন্ট্রোল
* **ইউটিউবে গান/ভিডিও প্লে:** *"জুবায়ের, ইউটিউবে কুরআন তেলাওয়াত চালাও"* অথবা *"ইউটিউবে [যেকোনো গান] চালাও"* -> স্বয়ংক্রিয়ভাবে প্লে হবে।
* **গুগল সার্চ:** *"জুবায়ের, গুগলে সার্চ করো আজকের খবর"*
* **ব্রাউজার খোলা:** *"জুবায়ের, ক্রোম খোলো"*

### ৩. ✍️ হাত ছাড়া মুখে বলে টাইপ করা (Voice Typing)
* *"জুবায়ের, নোটপ্যাড খোলো"* -> নোটপ্যাড ওপেন হবে।
* এরপর বলুন: *"জুবায়ের, লেখো [আপনার বক্তব্য]"* -> আপনি যা বলবেন তা সাথে সাথে বাংলা বা ইংরেজিতে টাইপ হয়ে যাবে!

### ৪. 🔊 সাউন্ড ও ভলিউম
* *"জুবায়ের, ভলিউম বাড়াও"* / *"ভলিউম কমাও"* / *"মিউট করো"*

## 🔒 অডিও ভয়েস লক (Biometric Voice Authentication)

* **নিজের কণ্ঠস্বর সেভ করার নিয়ম:**  
  সিস্টেম চালু করে বলুন: *"জুবায়ের, আমার কণ্ঠ সেভ করো"*। এরপর সে আপনাকে ৩ বার কথা বলতে বলবে এবং আপনার কণ্ঠের ইউনিক ফ্রিকোয়েন্সি বায়োমেট্রিক প্রোফাইল হিসেবে সেভ করে নেবে।
* **অন্য কেউ ডাকলে:**  
  অন্য কোনো ব্যক্তি ডাকলে জুবায়ের বলবে: *"অননুমোদিত কণ্ঠস্বর! আমি শুধু আমার মালিকের কথা শুনি।"*
* **জরুরি ব্যাকআপ পিন:**  
  ঠান্ডা লাগলে বা গলা বসে গেলে আপনার গোপন পিন (ডিফল্ট: `1234`) মুখে বললেই সে সাথে সাথে কমান্ড গ্রহণ করবে।

## 📱 মোবাইল দিয়ে দূর থেকে পিসি কন্ট্রোল (Smartphone WiFi Remote)

1. স্ক্রিনের ভাসমান **আর্ক রিঅ্যাক্টর অর্ব**-এ মাউস দিয়ে ডাবল-ক্লিক করুন অথবা মুখে বলুন: *"জুবায়ের, মোবাইল কানেক্ট করো"*।
2. স্ক্রিনে একটি **কিউআর কোড (QR Code)** ভেসে উঠবে।
3. আপনার স্মার্টফোনের ক্যামেরা দিয়ে স্ক্যান করলেই ফোনের ব্রাউজারে একটি সাই-ফাই রিমোট ওপেন হবে:
   - মোবাইল স্ক্রিনকে **মাউস টাচপ্যাড** হিসেবে ব্যবহার করে পিসির মাউস নাড়াতে পারবেন।
   - মোবাইলের বড় **মাইক বাটনে চাপ দিয়ে কথা বললে** পিসি কাজ করবে।
   - মোবাইল থেকে ভলিউম, স্ক্রিনশট, লক ও শাটডাউন করতে পারবেন।
   - কোনো অ্যাপ ইনস্টল করতে হবে না!

## 📁 আর্কিটেকচার ও ফাইল বিভাজন (Module Structure)

| ফাইলের নাম | কাজের দায়িত্ব |
|---|---|
| **`START_JUBAYER.bat`** | প্রধান লঞ্চার |
| **`INSTALL.bat`** | কাস্টম নাম ও পিন সেটআপ উইজার্ড |
| **`config.py`** | AI নাম, ব্যাকআপ পিন ও মূল সেটিংস |
| **`security/voice_lock.py`** | অডিও বায়োমেট্রিক ভয়েস লক ইঞ্জিন |
| **`core/wake_word.py`** | নাম শোনা ও বাংলা/ইংরেজি কমান্ড পার্সিং |
| **`actions/system_control.py`** | উইন্ডোজ শাটডাউন, লক, স্ক্রিনশট, সাউন্ড কন্ট্রোল |
| **`actions/voice_typing.py`** | ভয়েস-টু-টেক্সট টাইপিং ইঞ্জিন |
| **`mobile/remote_server.py`** | মোবাইল ওয়াইফাই রিমোট সার্ভার (Flask/WebSockets) |
| **`ui/arc_reactor_orb.py`** | স্ক্রিনের ভাসমান সাই-ফাই আর্ক রিঅ্যাক্টর উইজেট |
